# report/

- `report.md`: report skeleton (front page lists the selected exercises and the 100-point total). Convert to PDF, e.g.
  `pandoc report.md -o report.pdf` (or write it in your tool of choice) and keep the final `report.pdf` here for packaging.
- `tables/`, `figures/`: generated by `python3 scripts/summarize.py <exercise>` and your own plotting scripts. Everything
  here can be regenerated from `data/`.
